# Sentiment Analysis of YouTube Comments Using Fine-Tuned IndoBERT

Final Project / Undergraduate Thesis repository for sentiment analysis of Indonesian YouTube comments using Fine-Tuned IndoBERT.

## Research Overview

This research focuses on classifying Indonesian-language YouTube comments into three sentiment classes:

- Positive
- Negative
- Neutral

The dataset will be collected from the Korean Reomit YouTube channel, focusing on videos related to the Kim Soo Hyun and Kim Sae Ron case.

The main model used in this research is IndoBERT, which will be fine-tuned for sentiment classification.

## Research Pipeline

The research pipeline includes:

1. Data Collection
2. Data Filtering
3. Data Labeling
4. Text Preprocessing
5. Data Splitting
6. Fine-Tuning IndoBERT
7. Model Evaluation
8. Error Analysis
9. Web-Based System Implementation

## Model Evaluation

The model will be evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Technologies

- Python
- IndoBERT
- Hugging Face Transformers
- PyTorch
- YouTube Data API v3
